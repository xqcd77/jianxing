## 评测口径

两套系统各完整执行66题一次，独立沙箱，同一业务模型、数据、脚本、单次输出限制、全请求Token预算和16次角色调用上限。Single-Agent为统一业务规划与一轮通用研究基线，并非每题仅调用一次LLM；新架构为Supervisor及四子Agent。比较对象是两套完整系统，不能把差值全部归因于Agent数量。

严格通过须同时满足实际状态/授权/资金断言及全部必需语义要求。评分采用v12，五维权重为需求覆盖2、业务正确性2、证据推理1、可操作性1、表达清晰1；不适用维度不自动给满分。裁判失败列为未决，保留66题分母；有效低分不重判覆盖。除总分外单列原58题、记忆4题、上下文4题及每维有效样本数。
