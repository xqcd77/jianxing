# BankFlowBench-Lite58 · v1 · 2026-10-24

本版由原48题原样保留，加上`complex_requests_10.json`的C01—C10十个完整任务组成。口语改写4题、另4个多目标专项与单元测试数不进入58题分母。多轮对话仍算一个任务。

新增题在付费评测前转换为同一原生应用脚本、财务硬检查与五维语义验收契约，使用11项离线控制器检查验证可执行性。旧48题的每个Scenario与原版逐项相等，未修订其gold或历史校验清单。

严格通过必须同时满足全部业务硬检查及每条必需语义要求。未决保留在总分母，不当作通过。五维为需求覆盖、银行业务正确性、证据推理、可操作性、清晰度，权重2∶2∶1∶1∶1；不适用的维度不填零分或满分。

新增题覆盖三目标、开卡与充值语义、相对金额、预留资金、顺序比例计算、总金额与定投金额、多轮修改、已执行任务去重、新卡依赖引用以及同句否定改口。来自已参与开发的真实反馈，属于诊断开发集，不是独立盲测。

`public.jsonl`只含用户脚本；`private_gold.jsonl`仅供控制器与裁判使用，不提供给业务模型。ETF和银行资料为固定合成快照，不访问真实账户或实时行情。运行时另冻结源码、模型配置、场景文件与数据哈希。原48题和新增10题分别报告，不与旧版本成绩混算。
