# Supervisor＋4子Agent编排

默认配置：`BANK_ORCHESTRATION_MODE=supervisor`。旧架构与冻结评测使用`legacy`，两组历史基线与C组实现保持原有角色组合；既有成绩不重新标注为新架构成绩。

## 五个角色与六类规则服务

| 角色 | 判断空间 | 允许访问的能力 |
| --- | --- | --- |
| Supervisor | 选择办理或研究路径、分派角色、汇总结论、控制补查与结束 | 路由、研究约束提取、结果汇总；不能发出银行授权 |
| 账单研究 | 选择需关注的证据与缺项，核查流水、义务、异常及资金缺口 | 本人授权的账单、账户和现金流只读工具 |
| 理财研究 | 核对产品条款、适当性、期限与到账条件，选择关注结论和缺项 | 本人账户条件、模拟产品与披露只读工具 |
| 业务办理 | 在明确需求内形成动作参数和依赖，按核验反馈修订普通聊天草案 | 转账、账单、理财、卡片、代扣、跨场景六类规则服务；提交须经过独立网关 |
| 独立核验 | 审查需求覆盖、证据支持、产品绑定及计划约束，指出具体问题和修正目标 | 无交易工具；只读原始需求、候选结果和必要来源 |

六类领域组件是确定性规则服务，不再作为六个LLM Agent计数；确定性DAG校验器也不计入五个角色。旧节点的`agent`仍表示工具领域归属，供权限与账本兼容使用；计划审查中的`business_service_count`与`orchestration_roles`分别表示服务数和实际参与角色。

Supervisor和研究角色可以使用同一模型API，但每次请求上下文独立。独立核验使用单独的模型适配器和核验提示词，不能读取生产者的私有推理或完整共享历史。线上核验不是离线MiMo裁判，不混用两者的评测分数。

## 两条路径

明确单项办理或多项纯查询：Supervisor → 业务办理 → 规则服务与DAG检查 → 持久化计划 → 实时整份计划预检 → 按需确认或强验证 → 银行适配层 → 回执。纯查询自动执行，不增加独立模型核验。

组合办理：先对整份草案进行资金预检；余额不足等普通受阻直接说明所需资金、缺口与下一步，避免误判为安全异常。在持久化与任何银行执行之前，再增加独立语义核验。普通聊天草案按预算返回业务Agent修订；明确表单与研究选定方案不由模型擅自改写。核验超时、输出无效或超出修订预算时，停止提交并要求核对，不能默认放行。

复杂研究：Supervisor提取约束 → LangGraph Send并行账单与理财取证 → 程序核验哈希、权限、数值和时效 → 有界定向补查 → Supervisor汇总 → 独立语义核验 → 发布。核验问题映射回原角色，不重跑已经完成的其他角色。补查、模型重试、总体超时均有界。

不是所有研究分支都能独立完成：条款读取与流水核查可以并行；最终产品筛选和办理仍需结合统一资金条件。当前源读取先建立确定性事实，角色LLM在补查阶段选择关注结论；演示模式使用明确标识的规则回退。不能把节点名字视作每轮都实际调用了模型。

## 安全与一致性

- Supervisor全局安全排除先于研究匹配，后续正则不能覆盖绕过权限请求。
- 每个研究角色只接收自己的证据和结果；共享结果通过图状态合并，原始来源与业务指纹保留。
- 金额、日期、否定要求、版本及回执继续通过结构化字段传递。账本是资金事实来源，历史摘要和研究结论不提供授权。
- 独立核验引用必须来自已读取证据；定向补查工具按角色再次过滤。核验模型没有银行写入或授权能力。
- 独立核验发现问题、超时或返回无效结构时，不发布可办理研究方案。研究只能回退到已经程序核验的事实，并显式标记未完成。
- 模型汇总完成后、核验后和发布前复核业务指纹；金额或产品条件变化则标记过期。
- 报告、核验状态、候选方案与最终状态在同一事务发布，避免轮询提前看到缺少核验标识的报告。
- 资金操作仍须实时预检、分级授权、版本指纹、事务与幂等回执。研究选择方案不等于交易已获授权。

## 验证口径

新增回归覆盖：简单业务短路、五角色与六服务计数、双研究实际并行、上下文隔离、受影响角色定向修复、无效引用与跨域补查拒绝、核验超时、时效变化、组合办理阻断、核验通过仍需强验证。

最新冻结测量为2026-10-25完整58题、统一MiMo v11标准：Supervisor严格通过54/58（93.10%）、加权4.5984/5；Single Agent为41/58（70.69%下界）、加权3.9350/5，有2题未决不计通过。两组调用上限分别16与10，不是等预算消融；结果绑定冻结源码哈希。[逐题结果与比较边界](current58-comparison-2026-10-25.md)。

历史48题MiMo v8结果保留为Supervisor 44/48、4.6462/5，Single Agent 32/48、3.8451/5。不同评分版本不直接混比。[历史评测与可复算数据](evaluation.md)。
