# 简行功能演示流程

先按 deployment.md 启动项目，使用演示账户和新的合成数据目录。以下流程可按需要分别体验。

1. **工作台与手机布局**：查看账户余额、六类业务入口和对话区；手机页面将内容按单列展示。
2. **组合办理**：模拟入金4500元，提出两笔转账与剩余20%的理财研究，检查三项目标、预算520元和逐项状态。
3. **变更与续办**：未付款前将第二笔金额改为800元，检查研究预算660元；已完成转账保留回执。
4. **深度研究**：查看研究进度、结论、现金流核查、产品比较、来源与未知条件。研究后选择方案，再进入办理。
5. **敏感确认**：核对本次金额与对象，进入验证或风险测评，补齐条件后返回原任务。
6. **其他业务**：查看账单分析、卡片状态、模拟理财和已有订阅管理。
7. **记忆与模型**：从历史会话继续任务，查看上下文容量，选择模型厂商、具体型号并配置自己的API Key。
8. **停止与恢复**：停止未提交工作，回到历史检查未完成目标；已提交业务查询回执。

具体账户状态以沙箱账本为准。使用合成数据，外部资料不足时保留未知项。
