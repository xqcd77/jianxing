# 原版布局恢复与动态视觉升级

恢复了上一版的品牌副标题、首页介绍、余额说明、业务入口描述、办理引导、右侧规则说明与研究层级。保留已验证的多任务办理、测评导航、对话步骤时间线和逐字答复。

工作台沿用青绿与暖白风格，增加玉色卡面、内侧高光、柔和投影、光照跟随、轻量三维倾斜、悬浮入口、动态山水光环与分层入场。金额更新仅做视觉强调，不插值或改写账户数字。所有光影与装饰层均避免遮挡业务控件。

登录从小型弹窗升级为全屏深色舞台，使用原生CSS与SVG构建悬浮卡片、金属边缘、环绕轨道、光点与呼吸光晕。桌面为左右分栏，手机为上下排列；表单保留原认证接口、错误提示与退出后清空密码的行为。

登录按钮为48px高的全圆角原生按钮，外壳`padding:1px; overflow:hidden`。底层超大圆锥渐变使用`#E2CBFF → #393BB2 → #E2CBFF`，以`2s linear infinite`旋转；上层`rgb(2 6 23)`遮挡渐变，悬停时过渡到80%不透明度。键盘聚焦显示独立焦点环。系统要求减少动态效果时停止装饰动画，隐藏页面时暂停动画。

验收：

- `scripts/premium_ui_smoke.cjs`：1440/390宽度，实际采样旋转矩阵及卡片运动、2秒匀速设置、80%悬停背景、键盘焦点、登录失败与成功、信息恢复、鼠标倾斜、退出清空密码、减少动态效果和无横向溢出。
- `scripts/conversation_ui_smoke.cjs`：九项对话交互全部通过，含停止、重连、刷新、独立与混合研究。
- `scripts/multigoal_ui_smoke.cjs`：转账确认、大额验证、测评导航及刷新后返回原计划、无重复转账和研究报告，在桌面及手机均通过。
- 两份TypeScript配置及修改文件的空白检查通过。

视觉检查截图、浏览器原始记录位于本地`.data/premium-*`。完整结果见`premium-ui-verification.json`。验证使用隔离演示账户，未在主应用账户执行测试交易。本轮未更改模型提示词、资金规则或数据库结构。
