# 对话步骤与界面精简

对话按后台实际执行阶段展示时间线：理解安排、拆分任务、核对资金、生成办理卡片、查询资料及研究阶段。当前步骤使用逐字错峰的波浪动画，完成后自动折叠为耗时；点击可重新展开。这里展示的是服务端阶段事件，不读取或展示模型内部推理，也不新增模型调用。

最终答复通过原有校验后逐字显示，最长动画2.4秒，可点击“显示全文”立即展开。系统设置为减少动态效果时直接呈现全文。办理卡片可先于研究结果使用，不需要等待动画结束才授权。停止请求与停止独立分析分别使用原有取消接口；已经提交的业务以回执为准。

进度断线可重连，刷新可从持久化请求事件恢复；逐字显示结束前保留恢复标识。切换用户或前台任务后，旧动画停止，过期结果不能接管新会话。

页面移除了重复副标题、业务入口说明、Agent服务标签和重复状态说明。研究内容保留结论、数字、分析依据、产品对比；详细说明及原始证据在展开后查看，风险条件与授权入口保留。
