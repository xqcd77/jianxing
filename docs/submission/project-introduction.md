# 简行项目介绍

简行帮助用户用自然语言提出银行需求，将明确操作组织成可核对的任务，将复杂问题交给研究流程分析，再由用户决定是否办理。作品运行在合成金融沙箱，所有账户、资金、产品和交易均为演示数据。

## 创作理念

用户常把多项需求放在一句话中，例如“给妈妈转400元，给小王转1500元，剩余资金的20%做理财并给出建议”。传统菜单需要反复寻找入口，单次问答也容易遗漏后续需求。简行把每个目标单独记录，显示办理条件和进度，让用户知道哪些已经完成、哪些需要补充信息。

## 作品范围

六类菜单为智能转账、账单分析、理财操作、卡片管理、订阅代扣和跨场景联动，共31项主菜单入口。入口数量不等于底层工具数量。

明确需求进入直接办理路径。需要了解收支、比较产品或评估资金安排时，进入Deep Research路径。研究报告保留来源和待核实条件，用户选择后再进入办理。

## 核心技术

OpenAI Agents SDK执行角色调用，LangGraph管理流程与检查点，FastAPI提供接口和网页服务。Supervisor协调账单研究、理财研究、业务办理、独立核验四个子Agent。Harness记录预算、期限和运行事件。ChromaDB保存可重建的向量索引，SQLite保存任务状态、原文、授权、账本和回执。

## 已完成的验证

2026年10月28日冻结版本在BankFlowBench 10领域66题中严格通过64题，严格通过率96.97%，五维加权分4.7431/5。两项语义失败仍保留。评测集参与过开发，且本轮未重跑Single-Agent，不能把该数字解释为独立盲测结果、同版本架构对比或生产环境成功率。

## 能力边界

ETF公开资料查询与模拟理财申购属于不同能力，未接入证券购买和自动定投。商户会员新开通未接入，已有订阅的查询、提醒、停扣和解约按实际能力分别处理。原型不提供真实投资建议、银行认证或生产合规承诺。
