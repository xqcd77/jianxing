# 安全设计与当前边界

- 模型无账本写权限；工具归属、参数、DAG、授权和实际资金提交分别核验。
- 绿色自动、黄色确认、红色强验证。确认绑定业务内容与版本；金额、对象或报价变化后旧授权失效。
- 执行前展示整份计划的资金占用，事务内再次核验余额、预留、风险与限额。
- 转账、申购与结算使用整数分或定点计算、幂等键、原子提交与双边账本。提交超时先核实结果，不自动重复付款。
- 否定约束前置过滤；外部材料和模型文字不能签发Grant；结果展示以查询与回执为依据。
- 余额不足、锁定期未结束等普通条件受阻与异常凭证失败分开；异常验证才累计安全失败并熔断。
- 操作、核验、重规划和回执写入审计链。哈希链支持本地篡改核验，不等于不可篡改的外部存证。
- 共享记忆按用户、领域、来源与有效期过滤；历史余额和同意不能代替当前事实及新授权。
- 研究只读。报告候选选择后再次核验数据版本与适当性，不直接修改金融状态。
- 风险解释由RiskPolicyService复用银行分级、预检和回执生成，绑定计划版本、节点指纹和事实摘要；界面解释不构成Grant。
- 敏感操作使用统一核对弹窗与一次强验证；弹窗提交前回读当前资金及计划，条件变化后要求重新核对。普通受阻、结果未知与安全暂停分别展示。
- 申购校验模拟条款和目录关键条件及条款原句的一致性；缺失或冲突时不扣款。产品风险与身份验证强度分别展示。
- 未来30天压力时间线从当前可用资金回放计划变化及已登记代扣，预留变化单独计入，不再次从最终余额重复扣除代扣；预测不增加当前可用资金。
- 安全中心事件仅返回本人的白名单事件标题、时间与计划引用，不返回凭证、验证码或原始敏感详情。

.env、私钥、数据库、认证器、检查点与真实API运行轨迹不发布。源码私有与展示素材公开分离。界面中的金额、姓名与回执是合成沙箱资料。

演示验证码不是生产多因子认证；关闭BANK_DEMO_ENABLED或BANK_DEMO_VERIFICATION_ENABLED后服务端同时拒绝演示码的生成与使用。正式接入需要银行认证、真实适当性与清算约束、独立安全审查及真实数据脱敏，不能将当前沙箱测评解释为生产合规认证。

如发现安全问题，请私下联系仓库维护者；公开反馈只提供脱敏的复现步骤。
