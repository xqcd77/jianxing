## 展示顺序

1. 工作台全景与动态登录：建立产品场景。
2. 公开执行步骤与多目标清单：说明如何处理一句话里的多项需求。
3. 强验证与风险测评：展示真实的办理前置条件和授权入口。
4. 研究报告：结论、关键数字、核查维度、产品条件与证据入口。
5. 账单、理财、卡片、订阅：展示各类业务结果。
6. 资金影响与依赖、ETF资料：补充跨业务编排与公开资料能力。
7. 手机端：验证窄屏布局。

全景与研究报告使用单栏，内容相近的业务图使用双栏。手机图限制显示宽度，点击可查看原图。README共引用14张截图，没有额外加入重复的裁剪版本。
